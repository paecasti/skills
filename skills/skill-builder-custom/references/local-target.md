# Local Target

## Target path

Use the nearest project-level `skills/` directory. If none exists, create `skills/` at the current project root.

```txt
skills/<skill-name>/SKILL.md
skills/<skill-name>/references/body.md
```

Add extra reference files, scripts, templates, or resources only when the requested skill needs them.

## Naming

Convert user-provided skill names to lowercase kebab-case.

Do not add prefixes unless the user explicitly requests one or the existing project convention requires one.

Do not ask for platform, personal/global scope, upload format, CLI format, or OS path style.

Do not create personal/global skill folders, upload packages, or alternate skill directories.
